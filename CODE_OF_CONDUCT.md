# Code of Conduct

We want Better Realtime participation to be safe, constructive, and technically honest.

Communicate respectfully, critique ideas and evidence rather than people, protect private information, and avoid harassment, discrimination, threats, or sustained disruption. Maintainers may edit or remove contributions and restrict participation when behavior violates these expectations.

Use GitHub Issues for ordinary bug reports and feature requests. Report conduct concerns privately to support@byteloft.app. Do not use this address for security vulnerabilities; use GitHub Private Vulnerability Reporting instead.
